## Initial Setup (Use Case)

The user taps the microphone input. The AI receives the input, crafts a response, creates a schedule specifying the delivery time, and saves it to the local database.

## The Proactive Call Flow

The core innovation of LAFINA is its proactive call delivery system, which operates in five distinct stages:

1. **Trigger:** The background SQLite database detects that a specific reminder time has been reached.
2. **Call Initiation:** Instead of a push notification, the application triggers an actual outgoing phone call to the user's device using native calling interfaces and telephony protocols.
3. **Delivery:** When the user answers, the Kokoro 82M TTS module verbally delivers the pre-crafted reminder message over the active audio line.
4. **Acknowledgment:** The user must verbally acknowledge the reminder. The audio is captured over the line, processed by Whisper STT, and evaluated by SmolLM2 to confirm intent.
5. **Termination:** Upon confirmation, the AI generates a brief closing statement, automatically terminates the call, and marks the job queue as complete in the database.
