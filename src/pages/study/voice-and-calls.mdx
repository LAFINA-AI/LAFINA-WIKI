## The voice building blocks

| Block | Offline | Online |
|---|---|---|
| **Hearing (STT)** | whisper.cpp `tiny.en` (quantized `q5_1`) + **Silero VAD** | ElevenLabs (live voice) |
| **Speaking (TTS)** | Phone's speech engine via `react-native-tts` (needs an installed offline voice) | ElevenLabs voices through the backend |
| **Thinking** | Rule parser + optional on-device model | DeepSeek (via the backend) |

- **VAD (Voice Activity Detection)** tells LAFINA when you start and stop talking, so it knows when to transcribe.
- **Whisper targets** (in-app metrics): median about 1.5 s after you stop talking, 95th percentile under 3 s.
- **Speech "ghosts":** LAFINA filters Whisper's known hallucinations on silence and ignores its own voice echoing back.
- **Kokoro** is no longer used. The phone's TTS starts faster and uses less memory.

<Card title="Online call rules worth remembering">
  <ul>
    <li><strong>Nothing reaches the network before the local gates pass.</strong></li>
    <li>Each start gets a new <strong>generation</strong>. Late events from an old call are ignored and can't reopen the mic.</li>
    <li>It <strong>never restarts by itself</strong>. Going to the background, a phone call, a network drop, or losing audio focus all require a new tap.</li>
    <li><strong>Barge-in:</strong> if you interrupt, LAFINA stops talking and listens. An answer you didn't hear fully is saved as <em>interrupted</em>.</li>
    <li><strong>Persona:</strong> short spoken sentences, first person, no markdown. It never invents tool progress or saved actions, and treats notes as untrusted data.</li>
    <li><strong>Saving still needs approval:</strong> the model prepares a draft card, and only the student's explicit approval commits it.</li>
    <li><strong>Skills:</strong> "make flashcards" → LAFINA ends the call and opens the skill. It doesn't make them during the call.</li>
  </ul>
</Card>

| Offline call limit | Value |
|---|---|
| Max call length | 20 minutes |
| Silent listens before hanging up | 3 |
| Capture errors before stopping | 2 |
| Max transcription time per utterance | 25 s |
| Max response time per turn | 20 s |
| End-of-speech pause | 0.7 s |

Both call types report the **same snapshot** to the UI, so the call screen, mini bar, and app-wide call registry work with either.
