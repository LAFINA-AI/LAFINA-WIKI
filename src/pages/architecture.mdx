## Development Methodology

The project utilizes the **Agile** methodology. This supports flexible, iterative development, allowing features like voice input processing, reminder scheduling, and call-based notifications to be developed and tested progressively.

## Three-Layer Architecture

LAFINA is built upon a robust, offline-capable architecture divided into three distinct layers.

### Layer 1: UI/UX Layer
Built with **React Native**. This layer handles all user interaction, microphone input capture, and rendering of the Reminder and Job Queue components.

### Layer 2: AI Layer <Badge variant="success">Offline-First</Badge>
All models are open-source, run via GGML/C++ binaries, and operate entirely offline for privacy and accessibility.

* **Speech-to-Text (STT):** Whisper.cpp Tiny/Base (Quantized). Transcribes user voice into text.
* **Language Model (LLM):** SmolLM2-135M-Instruct. Interprets intent, extracts scheduling details, and crafts conversational responses.
* **Text-to-Speech (TTS):** Kokoro 82M. Converts the generated text responses into a natural-sounding voice output.

### Layer 3: Storage Layer
Utilizes Local Storage/Async Storage alongside a serverless **SQLite** database to securely hold scheduling data, pre-crafted responses, and call trigger times locally.

<Alert type="success" title="Privacy Assured">
  Because the AI Layer and Storage Layer run completely on-device, no sensitive scheduling data or audio recordings are ever transmitted to the cloud.
</Alert>
