## What LAFINA is

**LAFINA is an AI student companion for Android.** It holds a student's academic life (classes, tasks, events, time blocks, reminders, alarms, and notes) in a database on the phone. The student can manage it by **tapping, typing, or talking**. LAFINA also chats, helps with studying, answers USTP questions with sources, and **calls** the student when a reminder is due.

A separately maintained **Electron PC client** shares the same backend and account, so a student's synced records follow them between phone and PC.

### The layers inside the Android app

| Layer | Responsibility | Where in the code |
|---|---|---|
| **Presentation** | Screens, navigation, themes, onboarding, product tour, call UI | `App.tsx`, `src/ui` |
| **Application services** | Conversation, intent parsing, review cards, scheduling, skills | `src/ai`, `src/scheduler`, `src/skills` |
| **Local persistence** | One OP-SQLite database, migrations, stores, sync outbox, search indexes | `src/storage` |
| **Android / native** | Kotlin bridges and receivers. C/C++ JNI for Whisper and the local model. PDF and OCR | `android/app/src/main` |
| **Cloud boundary** | Cloud client, sync worker, voice session API | `src/cloud`, `src/sync` |

<Card title="Two important details">
  <ul>
    <li><strong>Live voice is special:</strong> the backend only <em>authorizes</em> a session. The phone then streams audio directly to ElevenLabs over a signed WebSocket.</li>
    <li><strong>Provider API keys stay on the backend.</strong> The app never contains DeepSeek, Pinecone or ElevenLabs secrets.</li>

## Technology stack

| Area | Technology |
|---|---|
| Mobile UI | React Native 0.86, React 19.2, TypeScript 5.9 (strict), Hermes |
| Native | Kotlin 2.1, JDK 17, C/C++ JNI, CMake, Android NDK 27 |
| Database | `@op-engineering/op-sqlite` 16.2, SQLite migrations, FTS5 search |
| Speech recognition | whisper.cpp + Silero VAD |
| Understanding | Rule-based fast-path parser + optional llama.cpp GGUF model |
| Speech output | `react-native-tts` (phone voice). ElevenLabs online |
| Alerts | Android `AlarmManager`, receivers, full-screen call activity |
| COR / files | PDFBox Android, ML Kit text recognition, document picker |
| Calendar | `rrule` (recurrence), `ical-js-parser` (.ics) |
| Backend | Python FastAPI on Vercel, Neon PostgreSQL |
| Online AI | DeepSeek, Pinecone, ElevenLabs |
| Testing | Jest, React Native Testing Library, ESLint, Prettier, TypeScript |
