## Hardware Requirements

To ensure real-time natural language processing without cloud connectivity, the target device must meet the following hardware specifications:

| Component | Specification |
| :--- | :--- |
| **Operating System** | Android 11.0 (API Level 30) or higher |
| **Architecture** | 64-bit (ARM64-v8a) |
| **Processor** | Octa-Core (2.0 GHz or higher recommended) |
| **Memory** | 4 GB RAM minimum |
| **Storage** | Minimum 1 GB free internal storage |
| **Connectivity** | Fully offline — no internet required for the core AI loop |

<Alert type="warning" title="Storage Allocation">
  The storage space is strictly required for localized AI model weights and database management.
</Alert>

## Software Requirements

The application is built upon a modern, cross-platform software stack:

| Category | Technology |
| :--- | :--- |
| **Framework** | React Native |
| **Languages** | JavaScript, TypeScript, C++ |
| **Database** | SQLite |
| **AI Engine/Runtime** | GGML / llama.cpp (via Whisper.cpp) |
| **Development Tools** | Visual Studio Code, Android Studio, Git/GitHub |

## System Evaluation Strategy

The system undergoes evaluation using a 5-point Likert scale (1 = Strongly Disagree to 5 = Strongly Agree). 

It utilizes the **System Usability Scale (SUS)** questionnaire to measure ease of use, functionality, and overall satisfaction, aligning with ISO/IEC 25010 standards for functional suitability.
