## One-liners

| Topic | Say this |
|---|---|
| **What is LAFINA?** | An offline-first AI student companion for Android that plans with you, talks with you, and calls you when it matters. |
| **Core problem** | Scattered planning tools, plus alert fatigue from easy-to-ignore notifications. |
| **Core idea** | Proactive simulated calls + a companion students actually use + the student confirms every AI change. |
| **Offline-first** | The phone's SQLite database is the source of truth. Cloud is optional. |
| **Understanding** | Rules first, then an on-device model, then DeepSeek online. Always validated. |
| **Safety** | AI proposes, the student confirms. Review cards, revision checks, receipts, Undo. |
| **Reminder call** | AlarmManager → admission checks → full-screen call → speak → Whisper → acknowledge or snooze. |
| **Call LAFINA** | Student-initiated voice chat. Online = ElevenLabs + DeepSeek. Offline = Whisper + rules + phone TTS. |
| **Sync** | Transactional outbox, version-based conflicts, 7 entity types. |
| **Ask USTP** | RAG with citations. Offline FTS5, online Pinecone + DeepSeek. "Couldn't verify" when unsupported. |
| **Privacy** | Nothing leaves the phone for a guest. Keys on the server. Consent for audio. |
