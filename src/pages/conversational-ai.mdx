## Task-Oriented Spoken Dialogue System (TOSDS)

LAFINA is explicitly defined as a **Task-Oriented Spoken Dialogue System (TOSDS)**. It is a closed-domain model designed to accomplish specific scheduling tasks.

It is important to note that LAFINA is **not** an open-domain chit-chat bot. It does not possess the capability to answer general knowledge inquiries, write essays, or engage in casual conversation outside of its scheduling parameters. This strict scoping allows the models to remain small enough to run offline.

For definitions of TOSDS and related terms, see the [Glossary](/glossary).

## Multi-Turn Interaction Loop

LAFINA completely redefines the standard reminder format.

We must contrast LAFINA against zero-turn alarms (which only ring) and single-turn voice commands (like asking Siri to set a timer). LAFINA requires a sophisticated **multi-turn, bi-directional exchange**. In this loop, the AI initiates the call, the user responds, the AI evaluates that response, and finally, the AI closes the loop autonomously.

## Intent Evaluation

A critical component of LAFINA's conversational intelligence is its nuanced intent evaluation.

Instead of relying on strict, rigid keyword spotting like "Yes" or "Stop", LAFINA utilizes the **SmolLM2** language model to evaluate natural language intent. For example, if a user replies with "Give me five minutes," the AI comprehends the request for a delay rather than failing due to a missing keyword.

For a deeper look at SmolLM2's capabilities, see the [AI Models](/ai-models) page.
