## Guest vs. account

| | Guest | Signed-in account |
|---|---|---|
| Identity | `local_guest_user` on this phone | Cloud account (backend, Neon) |
| Planner, alarms, reminder calls | ✅ | ✅ |
| Offline voice, local Ask USTP | ✅ | ✅ |
| Sync across phone and PC | ❌ | ✅ |
| Online AI, online voice, documents | ❌ | ✅ (Online Mode, subject to account access and limits) |

**Upgrading:** when a guest signs in or registers, their tasks, notes, schedule, and chats are **carried over to the account once**, without duplicates.

<Card title="Why one transaction?">
  If the record were saved but the outbox entry wasn't (for example, if the app crashed in between), that change would <strong>never sync</strong>. Writing both together means either both happen or neither does. This is called the <strong>transactional outbox</strong> pattern.
</Card>

## Versions and conflicts

Each synced record has a **version**. A local change remembers the **base version** it was edited from.

<FlowChart
  label="Conflict detection"
  steps={[
    { title: 'Local change sent with its base version', kind: 'start' },
    { title: 'Does the server still have that version?', kind: 'decision' },
    [
      { title: 'Accepted', text: 'New version returned', kind: 'end', edge: 'yes' },
      { title: 'Conflict recorded', text: 'Both copies kept in sync_conflicts (local + server version)', kind: 'stop', edge: 'no, someone else changed it' },
    ],
  ]}
/>

Nothing is silently overwritten. The conflict stores the local payload, base version, server version, and server payload.

## What syncs and what doesn't

| Syncs (7 entity types) | Stays on the device |
|---|---|
| profile | Alarm clocks |
| tasks | Floating LAFINA settings and most local settings |
| events | Downloaded models, recordings, attachments |
| time blocks | Delivery jobs and history |
| reminders | Handbook index |
| notes | |
| custom categories | |

**Chats** sync separately through chat history sync, up to **20 chats per account**.

<Alert type="warning" title="Sync is not a full backup">
  Clearing app data or uninstalling removes device-only content such as alarms and recordings. Sign Out and Clear All Data remove local leftovers thoroughly.
</Alert>
