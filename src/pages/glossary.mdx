## A

**AI Student Companion**
LAFINA's role: an assistant that does more than manage a schedule. It chats, answers questions, helps students study, remembers their preferences, and calls them about what matters.

**Alert Fatigue**
The desensitization that happens when a user gets too many notifications. The brain starts filtering them out as background noise, so reminders are missed or ignored. A main motivation for LAFINA's call-based reminders.

**AlarmManager**
The Android system service that LAFINA uses to schedule reminders and alarms. Android wakes the app at the right time, even if LAFINA is closed.

**ARM64 (arm64-v8a)**
The 64-bit processor architecture of modern Android phones. LAFINA's native AI libraries are built for ARM64.

**Ask USTP**
LAFINA's USTP assistant. It answers questions about the Student Handbook and campus information (dates, offices, portals, scholarships) and shows its sources. It works offline with a local knowledge pack.

## C

**Call LAFINA**
A hands-free voice conversation that the student starts. Online, it uses ElevenLabs and DeepSeek. Offline, it uses Whisper, the local parser, and the phone's voice.

**Chat Agent**
The online mode in which DeepSeek can use tools that run on the phone to look up the student's planner (up to 4 steps) and prepare one review card.

**Conversational AI**
AI that converses with people in natural spoken or written language. LAFINA combines task-oriented dialogue (planning) with open-domain conversation (companion chat).

## D

**DeepSeek**
The large language model provider LAFINA uses online for conversation, trivia and general questions, study help, and planning assistance. It is accessed through the LAFINA backend.

## E

**ElevenLabs**
The online voice provider for natural spoken replies and the live voice in online Call LAFINA.

## F

**Fast-Path Parser**
LAFINA's rule-based intent reader. It instantly understands clear commands without a model, and its result is used when its confidence is 0.85 or higher.

**FTS5**
SQLite's full-text search engine. LAFINA uses it to search the handbook offline.

## G

**GGUF**
The file format for language models run by llama.cpp. LAFINA's optional on-device models are quantized GGUF files.

**Guest Mode**
Using LAFINA without an account. All data stays on the phone.

## I

**Intent**
The structured meaning of a message: the action (for example `create_reminder` or `query_schedule`) plus details such as title, date, and time.

**ISO/IEC 25010**
An international standard model for software quality (functional suitability, performance efficiency, usability, reliability, security, maintainability). LAFINA's evaluation aligns with it.

## L

**llama.cpp**
An open-source C++ library for running language models on a phone's CPU. LAFINA uses it for the optional on-device models.

## M

**Memory**
Facts and preferences the student shares ("I'm a night owl", "call me Jo") that LAFINA saves and uses later. It can be viewed, edited, or turned off. Passwords, PINs, and payment details are blocked from being saved.

**Morning Briefing**
An optional spoken summary of the day that plays after the student dismisses their alarm.

**Multi-Turn Interaction**
A conversation that takes several back-and-forth exchanges. Examples: a reminder call (ring → speak → reply → close), or a chat follow-up like "move it to 4 PM".

## N

**NLU (Natural Language Understanding)**
Turning human language into meaning. In LAFINA, NLU is a layered pipeline: rules, then an on-device model, then DeepSeek when online.

**Notification Fatigue** → see *Alert Fatigue*

## O

**Offline-First**
A design in which the phone holds the working copy of data and core features don't need internet. Online services are optional extras.

**Online Mode**
The chat switch that lets LAFINA use online AI (DeepSeek) and voice (ElevenLabs). It requires a signed-in account and internet.

**Outbox (Sync Outbox)**
A table of pending changes waiting to sync. Each change is written together with its outbox entry in one database transaction.

## P

**Pinecone**
A vector database that the backend uses to retrieve USTP Handbook passages for online Ask USTP answers.

**Proactive System**
A system that takes the initiative instead of waiting for the user. LAFINA rings with a call when a reminder is due.

## Q

**Quantization**
Shrinking a model by storing its weights at lower precision (for example 4-bit or 5-bit), which cuts size and memory with little accuracy loss. LAFINA's Whisper and GGUF models are quantized.

## R

**RAG (Retrieval-Augmented Generation)**
Answering by first retrieving relevant source passages and then generating the answer from them, with citations. Used by Ask USTP.

**React Native**
A cross-platform framework by Meta for building mobile apps in JavaScript and TypeScript. LAFINA's interface is built with it.

**Reactive System**
A system that waits for the user. Traditional alarms and notifications are reactive.

**Review Card**
The confirmation card that LAFINA shows before saving any assistant-proposed change. The student can edit, cancel, or confirm.

## S

**Silero VAD**
A small voice activity detection model that tells LAFINA when the student has started and stopped speaking.

**Simulated Call**
LAFINA's in-app, full-screen incoming-call screen for reminders. It is not a real telephone call.

**SLM (Small Language Model)**
A language model small enough to run on a phone, such as SmolLM2-135M or Gemma 3 270M.

**SQLite**
A lightweight, serverless database embedded in the app. It is LAFINA's local source of truth.

**STT (Speech-to-Text)**
Converting speech into text. LAFINA uses whisper.cpp on the phone.

**SUS (System Usability Scale)**
A standard 10-item questionnaire for measuring usability.

## T

**Taglish**
A mix of Tagalog (Filipino) and English common in the Philippines, for example: "Paalalahin mo ako bukas ng three PM para sa meeting."

**TOSDS (Task-Oriented Spoken Dialogue System)**
A dialogue system built to complete specific tasks through speech. LAFINA's planner core works this way. Its companion side goes beyond it.

**TTS (Text-to-Speech)**
Converting text into spoken audio. LAFINA uses the phone's speech engine offline and ElevenLabs online.

## U

**USTP (University of Science and Technology of Southern Philippines)**
The university in Cagayan de Oro (CDO), Mindanao, where LAFINA was developed. Its students are the primary users.

## W

**Whisper.cpp**
A C++ port of OpenAI's Whisper speech recognition model for efficient on-device use. LAFINA uses the quantized `tiny.en` model.
