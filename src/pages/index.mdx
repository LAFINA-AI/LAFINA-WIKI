<Alert type="success" title="Welcome to the LAFINA Wiki">
  This is the official documentation for LAFINA, an innovative voice-first scheduler built for university students.
</Alert>

**LAFINA** is a mobile-based AI application specifically designed to combat "notification fatigue" among university students. 

Instead of passive push notifications, it uses a proactive, voice-first approach—initiating simulated human-like phone calls to ensure task compliance and schedule adherence. 

<Card title="Offline-First Approach">
  LAFINA's architecture is completely offline-first. This is crucial for students with unstable internet access, guaranteeing that schedules and AI interactions are always available securely on-device without cloud dependencies.
</Card>
