## The Three-Model Pipeline

LAFINA's voice intelligence is powered by a carefully selected chain of three specialized models, each chosen to maximize accuracy within the strict constraints of a mobile device with 4GB RAM.

| **Task** | Transcribes spoken user audio into text |
| **Size** | ~39 MB (Tiny) / ~74 MB (Base) |
| **Runtime** | Whisper.cpp — C++ port, no Python required |
| **Language** | Multilingual; handles Filipino accents & Taglish |

**Why Whisper over alternatives?**

Whisper was chosen for its exceptional robustness with accented and non-native English speakers. Competing options like CMU PocketSphinx have significantly lower accuracy with Taglish speech patterns, while cloud-based solutions (Google STT, Azure) violate the offline-first requirement.

The *quantized* Tiny/Base models reduce memory footprint by 50–70% compared to full-precision models with minimal accuracy loss for short scheduling commands.

**Why SmolLM2 over alternatives?**

| Model | Params | RAM Use | Why Not Chosen |
|---|---|---|---|
| **SmolLM2-135M** ✅ | **135M** | **723 MB** | Chosen — optimal for mobile |
| Qwen2.5-0.5B | 500M | ~1 GB | Too heavy for background execution |
| Regex / Rule-based | — | Minimal | Fails on messy, conversational inputs |
| GPT-4 / Cloud API | — | N/A | Requires internet; violates privacy model |

SmolLM2's instruct-tuned variant excels at structured output generation — it can be prompted to return clean JSON (`{"task": "study review", "date": "2025-05-14", "time": "18:00"}`) from conversational input like *"remind me to review my notes tonight at six."*

| Property | Detail |

| **Model** | Kokoro 82M |
| **Task** | Converts LLM-generated text into natural speech |
| **Size** | ~164 MB (Q4 quantized) |
| **Runtime** | GGML binary |
| **Voice Quality** | Natural prosody, low latency, suitable for phone calls |

**Why Kokoro over alternatives?**

Kokoro 82M was selected for its balance between voice naturalness and model size. Traditional rule-based TTS engines (eSpeak, Festival) produce robotic output unsuitable for a conversational phone call context. Larger neural TTS systems exceed LAFINA's memory budget.

Kokoro generates warm, natural-sounding audio that feels appropriate for a simulated phone call — a critical factor since the call metaphor relies on the voice sounding human-enough to trigger the user's social conditioning to engage.

## How They Chain Together

```
User speaks → [Whisper.cpp STT] → text transcript
text transcript → [SmolLM2 NLU] → intent + JSON schedule
JSON schedule → [stored in SQLite] → triggers at reminder time
At reminder time → [SmolLM2 generates reminder text]
reminder text → [Kokoro TTS] → audio over phone call
User speaks back → [Whisper.cpp STT] → acknowledgment text
acknowledgment text → [SmolLM2 intent evaluation] → confirmed / delay / reschedule
```
